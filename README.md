# 학생부 스토리 설계도

학생이 학교생활 활동을 작성하고 Excel 또는 PDF로 저장할 수 있는 정적 웹앱입니다.

## 사용

- 웹사이트: https://unofficial-node.github.io/student-story-workbook/
- 별도의 회원가입이나 GPT 연동 없이 사용할 수 있습니다.
- 입력한 내용은 서버나 GitHub에 전송되지 않고 사용 중인 브라우저의 로컬 저장소에만 보관됩니다.
- `엑셀 저장`과 `PDF 저장` 버튼으로 작성 결과를 내려받을 수 있습니다.

## 배포 구조

이 저장소의 `main` 브랜치는 GitHub Pages에 게시되는 최신 정적 빌드 파일만 보관합니다. 파일명에 포함된 문자열은 브라우저 캐시 갱신을 위한 빌드 해시입니다.

이전 빌드의 해시 파일은 최신 배포 시 제거하여 저장소에 누적되지 않도록 관리합니다.
